# Rime 公共配置

根目录 `default.yaml`、`key_bindings.yaml`、`punctuation.yaml` 来自 [rime/rime-prelude](https://github.com/rime/rime-prelude/tree/082425ea0684bca36474415d4a0e8db9b016487e)，固定提交 `082425ea0684bca36474415d4a0e8db9b016487e`。随包提供以避免依赖电脑上的 `/usr/share/rime-data`；五个主方案仍由 `default.custom.yaml` 指定。根目录 `symbols.yaml` 保留仓库原有的符号配置。
